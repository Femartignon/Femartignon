# Logos das companhias aéreas

Usados pelo cartão de embarque (`cartao-embarque-ida.html` / `cartao-embarque-volta.html`). O cartão monta a URL
a partir do campo `voo_ida_cia` / `voo_volta_cia` (código IATA):

`https://raw.githubusercontent.com/Femartignon/Femartignon/main/cartao-embarque-infield-2026/logos/<IATA>.png`

| Arquivo | Companhia |
|---|---|
| `LA.png` | LATAM Airlines — versão monocromática branca (o símbolo rosa sumia no vermelho) |
| `G3.png` | GOL |
| `AD.png` | Azul |

Especificação: logo oficial em **versão branca (negativo)**, PNG com fundo
transparente, **altura de 102 px** (exibido a 34 px: nitidez 3x nos iPhones
atuais; mínimo aceitável 68 px), largura proporcional até **600 px**, recortado
rente ao desenho, sem margem. Nome do arquivo = código IATA em maiúsculas.
